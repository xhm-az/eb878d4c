# PACC：可执行的部分审阅源码

[English](README.md) · [审阅指南](docs/REVIEW_GUIDE.md) · [方法对应](docs/METHOD_MAP.md) · [公开范围](DISCLOSURE.md)

本目录提供 PACC 的**部分参考源码**。公开的控制器、证据比较、诊断信息选择及固定动作评分基础层可以在无需模型的情况下独立检查与运行。这不是服务器实验实现的代码快照。

**论文接收后，将完整公开源代码。**

## 快速检查：无需模型，无需安装依赖

在解压后的仓库根目录执行：

```bash
python -B tools/run_contract_tests.py
python -B examples/control_flow_demo.py
python -B examples/scoring_demo.py
python -B tools/check_release.py
```

分别运行契约测试、合成控制流演示、评分到控制器的合成接入演示和静态发布检查。只使用 Python 标准库，不需要模型权重、网络服务或基准环境。

**实际验证结果：96 项无模型契约测试通过，五条控制流演示路径及评分接入演示均已运行。未运行模型、真实环境或基准实验。** 详见[验证范围](docs/VALIDATION.md)。

入口会阻止模型运行库导入和 socket 网络调用。这是对可信检查代码的防误用措施，不是执行任意代码的安全沙箱。

## 演示能检查什么

| 合成场景 | 可以观察的行为 |
| --- | --- |
| 直接提交 | 不请求修订，提交原候选 |
| EEA 触发修订 | 反证进入证据诊断；修订通过后提交 |
| PTA 触发修订 | 预设风险状态进入目标诊断，再进行复评 |
| 修订失败 | 恢复原候选 |
| PTA 弃权 | 不触发目标风险修订 |

演示实际调用公开控制器、证据比较、诊断构造函数和最终动作挂接。适配器、规划器与 PTA 评估器是明确标注的测试替身；其中只有符号化输入和预设类别状态，**不是实际模型输出、实验成绩或 PTA 有效性的证明**。环境名称仅用于选择控制器分支，不连接真实网站或任务。

## 本次公开的设计内容

- 开放世界证据比较：缺少证据不等于反证；直接证据冲突保持未知。
- 同状态复评：原候选与局部修订共享复制后冻结的公开证据快照；下一次提交决策重新取快照，单纯语法拒绝不获取快照。
- 固定动作评分基础层：因果移位、动作掩码、平均对数似然、padding／停止标记排除、相同动作 token 与条件一致性检查；公开桥接器实际执行评分，再交给私有风险策略。
- EEA 优先的风险路由，以及未运行、弃权、未触发和触发状态的区分。
- 诊断信息选择：证据诊断只收集明确反证或语法问题；目标诊断携带原动作和原目标；无诊断重试不携带结构化细节。
- 有界修订、相同流程复评及失败回退。
- 诊断输入不设内部评分、替代目标或数值参数字段；公开摘要只输出状态信息。

上述逻辑有实际实现并参与测试，不只是接口声明。[评分基础层](docs/SCORING.md)会根据传入的 logits 实际计算，不用固定值替代评分。测试也检查某个对照条件失败时整批弃权、不能选择性保留成功条件。演示的 logits 是人工构造的，风险决策是明确预设的，不是实际 PTA 判定或实验成绩。

## 继续保密的内容

PTA 的任务相关对照构造、支持比较与风险判定策略，完整环境规则库和事实提取，模型后端、精确提示词、完整基线及真实参数和实验协议均不打包。公开配置只保留模式选择，没有默认值、最优值、扫描点或替代实验数值。

没有附真实任务、实际轨迹、实验数据或模型权重；新增符号和数值输入是专门构造的测试夹具，不是真实模型输出或实验参数。源码中的计数器、软件版本和结构性常量不是核心实验参数。

审稿人可检查和运行公开部分，但不能仅凭本包核查私有 PTA、完整规则库或复现论文结果。[审阅指南](docs/REVIEW_GUIDE.md)列出了每项检查与其边界。实际环境接入见[接入约定](docs/INTEGRATION.md)。

本目录使用独立包名 `pacc_review`，不替换内部实现。作者、许可证、匿名性与后续公开范围说明集中在[公开声明](DISCLOSURE.md)。
