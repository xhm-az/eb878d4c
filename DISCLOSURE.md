# Disclosure and review scope

## Release classification and commitment

Partial reference source with model-free functional contracts. Not an experimental-system snapshot or independently reproducible benchmark archive.

**The full source code will be released upon acceptance of the paper.** This is a future commitment, not a claim of an existing acceptance decision.

## Inspectable and retained operations

| Operation | Public evidence | Remaining limit |
| --- | --- | --- |
| Receive an already selected action | Controller, final-action hook and contract tests | External planner generation/search |
| Compare public facts and preconditions | Three-valued comparator and symbolic tests | Actual environment grammar, rules and fact extraction are retained privately |
| Route EEA/PTA outcomes | Executable controller and categorical test fixtures | A preset fixture outcome does not validate PTA risk detection |
| Select diagnostic information | Executable typed-envelope builder and tests | Exact prompts and model-side serialization are retained privately |
| Recheck and select final action | Executable contracts and synthetic demo | No actual model revision or real environment |
| Fixed-action likelihood foundation | Actual causal scoring arithmetic, condition checks and an executable bridge | Actual model logits/masks, tokenization and semantic contrast validity are not verified |
| Complete PTA assessment | Private provider and decision-policy interfaces | Task-specific contrast construction, support-comparison/risk decision and configuration are retained privately |
| Reproduce reported performance | Not provided | Actual tasks, evaluators, logs and experiment protocol are not distributed |

Declared provenance and scope checks cannot independently prove that private providers used the claimed model or public information. Passing the public contracts does not verify the undistributed core assessment or paper results.

## Test-double boundary

The symbolic adapter, scripted target evaluator, scripted planner and recording environment exist exclusively in the example/test layer. The production controller never imports or substitutes them. They exercise actual public control, diagnostic and scoring logic using prescribed states/artificial matrices, not a model or a task benchmark. The scoring bridge computes genuine arithmetic over these artificial logits, while its demo risk policy remains explicitly scripted. No synthetic output is described as an empirical method result.

The public diagnostic envelope deliberately has no internal numerical-score, alternative-goal or core-setting fields. Its information-selection policy is now visible; exact textual prompts and private PTA internals remain undistributed.

## Suggested code-availability description

> We provide partial reference source with model-free contract tests and a runnable synthetic control-flow demonstration. The public release includes the submission controller, generic evidence comparison, diagnostic information selection, and planner interfaces. The release also includes a fixed-action likelihood foundation and tested scoring bridge. Task-specific contrast construction, support-comparison/risk policies, complete environment rules, model backends, exact prompts, and experimental configurations are retained privately during review. The full source code will be released upon acceptance of the paper. The current partial release is not sufficient for independent reproduction of the reported results.

This describes the current artifact and future commitment, not venue certification. The manuscript must still describe the scientific method sufficiently for evaluation. The promise covers source code, not unauthorized third-party redistribution or sensitive information.

## Data and parameter handling

- No real task records, benchmark results, trajectories, paper files or model weights are bundled.
- Symbolic and numerical fixtures are included for executable tests and demonstration; they are not measured observations, actual model outputs or tuned settings.
- No numerical core configuration, decoding setting, task/trial budget, scan range or seed is published.
- The settings schema contains public mode selection only.
- Runtime contexts, decisions and diagnostic envelopes can contain private task/evidence text. Real logits and returned numerical likelihoods can also be sensitive. Do not serialize them wholesale.
- `Decision.public_summary()` selects categorical/Boolean metadata; it is not a universal redaction guarantee.
- Ignore rules do not remove already tracked content or earlier commits.

## Identity, hosting and authorization

No personal identity or machine-specific path is included in this source package. Repository ownership, commit authorship, old releases, linked accounts and external hosting need an independent anonymity check. No license, acceptance claim or DOI has been assigned. The later source release does not imply a current license grant or protection against copying.

The controller is not a hard execution shield: failed re-evaluation returns the original action. Non-flagged and abstained states do not certify task progress.
